PrautCleaner

PrautCleaner je desktopová konzole pro správu flotily lokálních Git repozitářů. Tauri aplikace sjednocuje inventuru, stav větví a auditované hromadné Git/GitHub operace do jednoho workflow.

Moje výrobky

Problém a přínos

Proč projekt vznikl

Vývojář získává jednotný přehled nad větším počtem pracovních kopií a může opakovatelné úkony provádět řízeně s potvrzením, logem a obnovitelnou karanténou.

Realizace

Jak jsem ho stavěl

Postavil jsem Tauri 2 aplikaci s Rust backendem a React/Vite rozhraním. Implementoval jsem sken lokálních repozitářů, práci s větvemi, backup, sync, merge a archivaci, doplněné o potvrzovací hranice a JSONL auditní stopu. Nástroj zůstává privátní a před distribucí potřebuje další testování a hardening.

Reflexe

Co jsem se při projektu naučil

Naučil jsem se navrhovat desktopový nástroj pro hromadné Git operace tak, aby rychlost nikdy nepřebila bezpečnost. Potvrzovací hranice, zálohy a JSONL auditní stopa mi ukázaly, jak důležité je u potenciálně destruktivních akcí zachovat dohledatelnost a možnost kontroly. Tauri s Rust backendem mi zároveň umožnil oddělit systémové operace od prezentační React vrstvy.

Ověřené důkazy a publikační hranice

Auditovaný commit 326e802f7ef5 · Privátní desktopová aplikace

Ověřené v repozitáři

  • Desktopová architektura kombinuje Tauri 2, Rust a React/Vite.
  • Aplikace inventarizuje lokální repozitáře a řídí commit, sync, backup, merge, archivaci a karanténu.
  • Hromadné operace doplňují potvrzovací dialogy, obnovitelná karanténa a JSONL auditní log.

Stav a hranice

  • Archivace může po vytvoření zálohy fyzicky odstranit lokální pracovní adresář.
  • Hromadné commity, push, rebase a merge jsou vysoce dopadové operace a nejsou bezrizikové.
  • Před veřejnou distribucí chybí CI, testy, podepsaný release, licence a bezpečnostní hardening.
