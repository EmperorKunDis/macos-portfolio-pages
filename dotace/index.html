Dotace

Dotační radar sjednocuje veřejné dotační výzvy do jednoho vyhledatelného read-only přehledu. Python pipeline získává data z katalogů a sitemap, normalizuje termíny, deduplikuje záznamy a generuje statický dataset pro rychlý webový frontend.

Moje výrobky

Problém a přínos

Proč projekt vznikl

Firmy, obce, školy, neziskové organizace a poradci mohou procházet více veřejných zdrojů na jednom místě. Každá položka zůstává dohledatelná k původnímu zdroji a frontend nevyžaduje účet ani backendovou databázi.

Realizace

Jak jsem ho stavěl

Navrhl jsem standard-library Python pipeline se sitemapovými a HTML adaptéry, stabilními hashovými ID, normalizací, deduplikací a validačními kontrolami. Výsledný data.js obsluhuje statický JavaScript frontend s fulltextem, filtrováním a řazením. Aktualizaci i Pages nasazení spouští GitHub Actions.

Reflexe

Co jsem se při projektu naučil

Naučil jsem se postavit datovou pipeline pouze nad standardní knihovnou Pythonu a přitom zachovat stabilní identifikátory, normalizaci, deduplikaci a validační kontroly. Oddělení sitemapových a HTML adaptérů mi usnadnilo práci s různými zdroji. Statický JavaScript frontend a automatická aktualizace přes GitHub Actions mi ukázaly, že read-only katalog lze provozovat jednoduše bez aplikačního backendu.
