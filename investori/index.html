Investor Radar

Investor Radar je živý výzkumný dashboard pro orientaci mezi fondy, angel investory, akcelerátory a grantovými příležitostmi. Umožňuje vyhledávání, detail, transparentní prioritizaci a CSV export.

Ověřené důkazy a publikační hranice

Auditovaný commit 7d073d30a2d9 · Živý automatizovaný výzkumný dashboard

Ověřené v repozitáři

  • Statický dashboard nabízí vyhledávání, detail, prioritizaci a CSV export investorů a zdrojů.
  • Dataset třídí fondy, specializované fondy, angel investory, akcelerátory, granty a veřejné zdroje.
  • Python a GitHub Actions pravidelně obnovují data a transparentní heuristiku skóre.

Stav a hranice

  • Nejde o Django/PostgreSQL/Angular CRM ani systém pro správu investorských vztahů.
  • Skóre není AI predikce, investiční doporučení ani důkaz zájmu konkrétního investora.
  • Osobní kontaktní údaje nejsou součástí portfolia a jejich aktuálnost a právní režim vyžadují kontrolu.
