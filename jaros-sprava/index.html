Jaroš Správa

Jaroš Správa je vícejazyčná digitální prezentace služby správy pronajímaných nemovitostí. Web vysvětluje přínosy, čtyřkrokový proces spolupráce, tři tarifní varianty, reference, FAQ a poptávkový tok.

Produkt

Problém a přínos

Proč projekt vznikl

Složitá služba je rozdělena do jasných kroků a porovnatelných tarifů, takže majitel rychle pochopí rozsah nabídky. Šest jazykových variant zpřístupňuje prezentaci i zahraničním vlastníkům.

Realizace

Jak jsem ho stavěl

Vytvořil jsem staticky exportovanou Next.js aplikaci v TypeScriptu s next-intl a Tailwind CSS. Obsahové bloky, tarify a FAQ jsou oddělené od prezentačních komponent a sestavení automatizuje GitHub Actions. Před veřejným použitím je nutné opravit URL strategii, assety, privacy tok a formulář.

Reflexe

Co jsem se při projektu naučil

Naučil jsem se oddělit obsahové bloky, tarify a FAQ od prezentačních komponent, aby se web dal měnit bez zásahů do layoutu. Lokalizace přes next-intl mi ukázala význam stabilní struktury obsahu napříč jazykovými verzemi. Při přípravě statického exportu jsem si ověřil, že URL strategie, assety, privacy tok a formulář musí být dokončené před tím, než lze build považovat za veřejně použitelný.
