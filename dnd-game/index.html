D&D Game

D&D Game je TypeScriptový technický základ pro budoucí multiplayer D&D 5e zážitek s AI vypravěčem. Monorepo propojuje pravidlový engine kostek, sdílené multiplayer typy, databázový model kampaní a základ AI postav.

Problém a přínos

Proč projekt vznikl

Sdílené typy a samostatný pravidlový engine vytvářejí základ, na kterém lze stavět konzistentní klientské i serverové herní mechaniky bez duplikace logiky.

Realizace

Jak jsem ho stavěl

Navrhl jsem npm/Turborepo monorepo pro Expo klienta, Express/Socket.IO server a sdílené TypeScript balíčky. Implementoval jsem pokročilejší parser hodů, Prisma model kampaní a kontextovou vrstvu AI postav. Mobilní UI a serverový entrypoint jsou zatím nedokončené, proto profil projekt označuje jako technický koncept.

Co jsem se při projektu naučil

Naučil jsem se sdílet typy a doménovou logiku mezi mobilním klientem a realtime serverem v jednom Turborepo monorepu. Parser hodů, model kampaní a kontextová AI vrstva mi ukázaly, jak rychle roste složitost digitálních pravidel stolní hry. Nedokončené mobilní UI a serverový entrypoint jsem se naučil otevřeně označit jako hranici technického konceptu, ne jako hotový produkt.

Repo audit · 2026-08-04

Ověřené důkazy a publikační hranice

Auditovaný commit f0c26a76c201 · Technický základ a architektonický koncept

Ověřené v repozitáři

  • Pravidlový engine podporuje D&D hody včetně advantage/disadvantage, keep/drop, rerollů a explozí.
  • Monorepo definuje sdílené doménové a Socket.IO typy pro multiplayer.
  • Serverová část obsahuje Prisma datový model, AI context builder a OpenRouter klienta s fallbackem.

Stav a hranice

  • Mobilní aplikace má pouze manifest; její zdrojový kód a AR funkcionalita chybí.
  • Server nemá doložený vstupní bod, API routy ani seed očekávané deklarovanými skripty.
  • Chybí testy, CI, lockfile, deployment a reprodukovatelný build.
