PostHub

PostHub je multi-tenant SaaS MVP pro firmy a agentury, které spravují více značek. Spojuje firemní kontext, AI persony, témata, blogové a sociální návrhy, schvalování, role, obsahový kalendář a subscription billing.

Problém a přínos

Proč projekt vznikl

Oddělená data a role umožňují řídit více klientů v jednom workspace. Dlouhé AI úlohy běží asynchronně a jejich stav se propisuje do rozhraní přes SSE, takže uživatel nemusí čekat na blokující požadavek.

Realizace

Jak jsem ho stavěl

Navrhl jsem full-stack monorepo s Angular SPA a Django REST API. Produktová data ukládá PostgreSQL s pgvector, úlohy zpracovávají Redis a Celery a předplatné obsluhují podepsané Stripe webhooky. Součástí repozitáře jsou kontejnery, Nginx, Kubernetes manifesty a rozsáhlé backendové i frontendové testy.

Reflexe

Co jsem se při projektu naučil

Naučil jsem se rozdělit produkt mezi rychlé SPA rozhraní, REST API a asynchronní frontu tak, aby dlouhé úlohy neblokovaly uživatele. Podepsané Stripe webhooky mi ukázaly, že fakturační integrace potřebuje vlastní bezpečnostní a stavovou logiku, ne jen tlačítko v UI. Kontejnery, Kubernetes manifesty a testy jsem řešil současně s produktem, protože provozní připravenost se nedá spolehlivě doplnit až na konci.
