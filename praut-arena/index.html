Problém a přínos

Proč projekt vznikl

Krátký tříminutový formát umožňuje okamžitě spustit hru v prohlížeči bez instalace. Žebříček a několik typů zbraní podporují opakované hraní a porovnání výsledků.

Realizace

Jak jsem ho stavěl

Arénu jsem postavil přímo jako součást portfolia nad Three.js a WebGL2. Implementoval jsem pohyb a míření přes Pointer Lock, tři zbraně, robotické protivníky, časovaný herní režim, Web Audio a serverově ověřovanou výsledkovou session pro žebříček.

Co jsem se při projektu naučil

Naučil jsem se implementovat pohyb a míření přes Pointer Lock a napojit robotické protivníky a časovaný herní režim nad Three.js a WebGL2. Řešil jsem i ozvučení přes Web Audio a serverově ověřovanou výsledkovou session pro žebříček, aby výsledky nešlo podvodně upravit na klientovi.

Repo audit · 2026-08-04

Ověřené důkazy a publikační hranice

Auditovaný commit 3665db8039f1 · Živá prohlížečová hra

Ověřené v repozitáři

  • Three.js/WebGL2 FPS nabízí tři zbraně, tři typy robotů, power-upy, Web Audio a dotykové ovládání.
  • Server vydává jednorázovou session, ukládá hash tokenu a transakčně přijme jeden výsledek.
  • Cílených deset testů, Quality workflow, Deploy workflow i živá herní URL byly na auditovaném SHA zelené.

Stav a hranice

  • Anti-cheat je heuristický, protože herní simulace a odesílané statistiky vznikají na klientovi.
  • Rate limit je procesový a živá MySQL cesta není pokrytá skutečným end-to-end testem.
  • Bez WebGL2 není hratelný fallback a výkon se může lišit na slabších mobilních GPU.
