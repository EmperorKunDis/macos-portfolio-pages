Záměr projektu

Prototyp ukazuje, jak zpřehlednit energii, materiálové toky a provozní ukazatele v jednom rozhraní. Umožňuje posoudit informační strukturu bez připojení k reálné technologii.

Zdrojově prověřený popis

Realizace v dostupných podkladech

HTML, CSS a JavaScript tvoří samostatnou aplikaci bez build kroku. Chart.js je součástí HTML. Seedovaný generátor vytváří demonstrativní řady, jednotlivé pohledy se sestavují na požádání a grafy se inicializují až po zobrazení plátna.

Ověřené důkazy a publikační hranice

Auditovaný commit · Interaktivní statický prototyp

Ověřené v repozitáři

  • README výslovně uvádí syntetická data a Chart.js vložený v index.html.
  • Generátor časových řad používá seed; registr pohledů odděluje sestavení HTML a inicializaci grafů.
  • Kód kontroluje rozměry viditelného plátna a při problému omezeně opakuje inicializaci.

Stav a hranice

  • Dohledaný projekt neobsahuje backend, živou SCADA integraci ani řízení zařízení.
  • Provozní hodnoty neslouží jako měření skutečné bioplynové stanice.
  • Konfigurace Cloudflare Pages v README není doklad dostupnosti produkční integrace.
