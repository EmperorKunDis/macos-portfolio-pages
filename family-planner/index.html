FamilyPlanner

Moje výrobky

Problém a přínos

Proč projekt vznikl

Návrh soustředí opakující se domácí povinnosti, odpovědnost a motivaci do jednoho přehledného rozhraní použitelného na běžných desktopových platformách.

Realizace

Jak jsem ho stavěl

Připravil jsem C++20 aplikaci s wxWidgets a CMake, rozdělil hlavní okno na členy, úkoly, odměny, vlastnosti a náhled rozvrhu. Současný stav je UI skeleton určený pro další doplnění datového modelu, event handlerů a plánovací logiky.

Reflexe

Co jsem se při projektu naučil

Naučil jsem se rozvrhnout desktopové UI do samostatných oblastí pro členy, úkoly, odměny, vlastnosti a rozvrh dřív, než vznikne finální datový model. wxWidgets mi ukázal praktické rozdíly mezi webovým a nativním rozhraním. Současný UI skeleton mi zároveň pomohl přesně pojmenovat, co ještě chybí: event handlery, plánovací logika a trvalá data.
