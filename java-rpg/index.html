JavaRPG

JavaRPG je rozsáhlý 2D desktopový RPG prototyp postavený v čisté Javě nad Swing/AWT. Obsahuje vlastní game loop, dlaždicovou mapu, kameru, entity, kolize, animace, dialogy, monstra, události, uživatelské rozhraní a zvuk.

Problém a přínos

Proč projekt vznikl

Projekt ukazuje stavbu herního základu bez komerčního enginu a jasné rozdělení zodpovědností mezi herní smyčku, mapu, entity, vstup, kolize a UI. Je vhodný jako technická ukázka práce s Java 2D grafikou a stavovým gameplayem.

Realizace

Jak jsem ho stavěl

Napsal jsem vlastní update/render loop, správu dlaždicového světa a kameru s ořezáváním renderované oblasti. Hierarchie entit pokrývá hráče, NPC a monstra, zatímco samostatné moduly řeší kolize, události, vstup, zvuk a UI. Prototyp je obsahově rozsáhlý, ale před distribucí potřebuje standardní build, vyčištění assetů a dokumentaci.

Co jsem se při projektu naučil

Naučil jsem se postavit vlastní update/render loop, dlaždicový svět a kameru s ořezáváním renderované oblasti bez herního enginu. Rozdělení hráče, NPC a monster do hierarchie entit mi ukázalo, kde oddělit kolize, události, vstup, zvuk a UI do samostatných modulů. Rozsah prototypu mi zároveň připomněl význam standardního buildu, čistých assetů a dokumentace pro další použití.
