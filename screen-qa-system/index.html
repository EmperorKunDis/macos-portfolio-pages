Screen Q&A System

Nástroj, který ze screenshotu obrazovky vytáhne text pomocí OCR, rozpozná v něm otázku a pomocí lokálního RAG systému nad vlastní znalostní bází vygeneruje odpověď. Celý proces běží lokálně bez závislosti na externím API, včetně LLM inference.

Moje výrobky

Problém a přínos

Proč projekt vznikl

Hodí se všude, kde je potřeba rychle zodpovědět otázku, kterou vidím na obrazovce (test, formulář, dokumentace), aniž bych musel text ručně přepisovat nebo posílat data mimo svůj počítač. Díky lokálnímu běhu je řešení vhodné i pro citlivější data, kde nechci nic odesílat do cloudu.

Realizace

Jak jsem ho stavěl

Řešil jsem hlavně spolehlivost OCR na různě kvalitních screenshotech a odfiltrování šumu (UI prvky, ikony) od skutečného textu otázky. Detekci otázky v extrahovaném textu jsem postavil na jednoduchých heuristikách a promptu pro LLM, aby to zbytečně nepřerostlo do složitého NLP pipeline. Pro odpovědi jsem sestavil lokální RAG nad vlastní znalostní bází, takže model odpovídá s kontextem, ne jen z obecných znalostí. Celý stack jsem drženě lokální i s LLM inferencí, aby řešení nezávisela na žádném externím API a data nikam neodcházela.

Reflexe

Co jsem se při projektu naučil

Naučil jsem se, že spolehlivost OCR na různě kvalitních screenshotech je největší slabina takového systému a musel jsem odfiltrovat šum jako UI prvky a ikony od skutečného textu otázky. Detekci otázky jsem postavil na jednoduchých heuristikách kombinovaných s promptem pro LLM. Rozhodl jsem se držet celý stack lokální i s LLM inferencí, což vyžadovalo postavit RAG nad vlastní znalostní bází.
