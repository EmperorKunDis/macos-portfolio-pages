Jaroš Reko

Jaroš Reko je responzivní vícejazyčný web pro rekonstrukce bytů a domů. Statická Next.js prezentace vysvětluje nabídku služeb, pětikrokový proces spolupráce, ukázkové projekty, reference a kontaktní cestu.

Produkt

Problém a přínos

Proč projekt vznikl

Web strukturuje složitou nabídku rekonstrukčních služeb do srozumitelného procesu a šesti jazykových variant. Statický export je rychlý, snadno hostovatelný a nevyžaduje aplikační backend.

Realizace

Jak jsem ho stavěl

Postavil jsem komponentovou Next.js aplikaci v TypeScriptu, napojil lokalizace přes next-intl a připravil statický export s automatizovaným Pages buildem. Součástí jsou služby, proces, projektové karty a responzivní kontaktní tok. Před plným zveřejněním je potřeba opravit base path, assety a nakonfigurovat formulář.

Reflexe

Co jsem se při projektu naučil

Naučil jsem se skládat lokalizovaný klientský web z opakovatelných komponent pro služby, proces, reference a kontakt. Statický export mi ukázal, že base path a assety je potřeba testovat ve skutečném cílovém prostředí, ne jen v lokálním dev serveru. Nedokončený formulář mi zároveň pomohl jasně oddělit hotovou prezentační vrstvu od ještě nenapojené provozní funkce.
