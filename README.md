# macos-portfolio-pages

Public, artifact-only GitHub Pages repository for the standalone project presentations linked from [svanda.tech](https://svanda.tech/projekty).

The repository contains generated static output only. The private Next.js source application, deployment configuration, databases, caches, and working notes are intentionally excluded.

## Published scope

- 39 one-pagers: 38 numbered non-component projects plus PRAUT//ARENA;
- searchable and filterable root catalog;
- one static route per published project;
- canonical metadata, sitemap, robots policy, and `.nojekyll`;
- technology-by-responsibility and author-learning sections;
- repository audit facts only where an audited public source is available.

Components do not receive standalone one-pagers. Their documentation stays in the main portfolio profile and, where a repository exists, in that repository's README.

## Deployment

`.github/workflows/pages.yml` publishes the repository root to GitHub Pages on every push to `main`. The expected public base URL is:

```text
https://emperorkundis.github.io/macos-portfolio-pages/
```

## Generation boundary

Files are generated by `scripts/generate-project-pages.mjs` in the private `macos-portfolio` source repository. Do not edit generated HTML, CSS, JavaScript, JSON, sitemap, or robots files manually: the next publication replaces them.

Before publishing a new artifact, the source pipeline verifies:

- 39 projects in `projects.json`;
- 40 `index.html` files including the root catalog;
- no component profile in the artifact;
- every technology assigned to exactly one project area;
- no internal working notes or credential-like values;
- canonical and one-pager URLs pointing to this repository.

## Public-data policy

This repository must never contain:

- source code from the private portfolio application;
- `.env` files, API keys, tokens, credentials, or database exports;
- private repository copies or internal infrastructure details;
- personal, client, financial, medical, or other non-public operational data.
